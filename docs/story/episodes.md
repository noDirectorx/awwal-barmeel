# خريطة الحلقات

| # | الاسم | الحال | الخلاصة |
|---|---|---|---|
| 1 | بريال | منشورة | تشغيل المضخة، أول تسليم، قرار الرواتب أو الخزان، الرسالة «لا توقّع» واكتشاف أن البرميل ملحوم |
| 2 | الزائر | منشورة | الخواجة يبغى البرميل (إخفاء أو مواجهة، عرض 50 ألف)، منيرة، شهر شغل، القيادة، توزيع الفلوس، فتح البرميل: رمل وأوراق شراكة. «كنت أدعي إنك ما تلقاها» |
| 3 | — | لم تُكتب | البحث عن عائلة راشد والتحقق من الأوراق، مع ضغط الخواجة والفريق |
| 4 | — | مخططة | كشف الحادث، تحالف له ثمن، الطريق البديل (يبني على `oldRoad`) |
| 5 | — | مخططة | الحريق |
| 6 | — | مخططة | آخر تسليم وقرار الحق |

النص الكامل مستخرج في `ep1-script.md` و`ep2-script.md`.

## متغيرات تنتقل للحلقات القادمة (`save.flags`)
| المتغير | المعنى |
|---|---|
| `decision` | 0 رواتب، غيره خزان |
| `mubarakLeft`, `mubarakAdvance` | مبارك طلع / أخذ ألفين |
| `q1`, `q2` | أصلح الوصلة / الكفر لناصر |
| `hid`, `caught`, `khawajaSuspect` | خبّى البرميل / انكشف / شك الخواجة |
| `helmetLeft` | الخواجة ترك خوذته عند عبدالله: **لازم تُعالج في ح3** |
| `answer` | رده على الخواجة |
| `muniraOpen`, `muniraQ`, `muniraKnows` | علاقة منيرة وسر الأرقام |
| `oldRoad` | اكتشف الطريق القديم |
| `crew` | توزيع الشباب |
| `kept`, `cash`, `tool`, `mbPaid`, `crewPay`, `arrears` | البراميل الواصلة والفلوس والعدة والرواتب |
| `radio` | الشريط |
| `sec_*` | الأسرار |

عند أول كتابة للحلقة 3 راجع الاستخدام الفعلي بالبحث في `source/ep2_ch.js`.
