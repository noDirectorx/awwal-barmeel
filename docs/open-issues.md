# الباقي

## 1. الأصوات (ننتظر رأي شادي بعد اللعب)
- محرك الشاحنة مع السرعة، كلام السوق بعد قص 15 ثانية، إزعاج صوت الجلخ، وتوازن المستويات.
- `fx_rumble` بلا أصل محفوظ، والموجود نسخته المعالجة.
- قبل أي نشر تجاري: مراجعة رخص الأصوات (`docs/audio-credits.md`).

## 2. نواقص وتدقيق القصة
- لم يراجع شادي بعد نصوص «الطريق القديم» ومهمة مؤشرات منيرة الجديدة.
- لازم تدقيق كامل للحلقتين من التناقض والغموض، على النص الفعلي في `docs/story/`.
- ملاحظات GPT الخام في `docs/review-notes/`. **كثير منها عولج، والحالة أدناه من قراءة النص الحالي فقط، وليست تدقيقًا نهائيًا.** تصحيح سابق: رحلة ناصر ذهابًا وإيابًا ليست تناقضًا.

| ملاحظة على ح2 | الحالة الظاهرة في النص |
|---|---|
| أثر قرار الخزان | موجود في المهمة (ترقيع الشرخ) وفي الحساب (`leak`) |
| «الكاش قبل الديزل» | وكيل الخواجة دفع مقدمًا وخصمه |
| سقوط البراميل | غرامة تدخل في `cash` |
| مَن يدفع في السوق | وكيل الخواجة |
| منيرة بنت حمدان | يعرّفها حمدان |
| إذن مبارك لإصلاح ماكينته | هو يطلبها |
| لماذا تأخر الفتح | العدة وثمنها مع حساب الشهر |
| عرض الخواجة | 50 ألف صريحة |
| تعطيل الخواجة | «طف المضخة» يسأل عنها |
| **الرمل في البرميل** | مثبت في المرجع، **ولا يقوله النص** |
| **ترك الخوذة** | يحتاج أثرًا لاحقًا، خاصة أن الخواجة يظهر بها دائمًا |
| **أثر الإخفاء أو المواجهة** | متغيرات محفوظة، وأثرها لم يُكتب بعد |
| **مهلة الرد** | 6 ثوانٍ؛ لم تُضف إعدادات لتعطيلها |
| **تعدد حالات رد مبارك على الرواتب** | لم يُدقق بعد لكل فرع |
