# أول برميل: ملفات المصدر

- `px_game.html`: كود اللعبة.
- `px/`: الرسومات بعد التنظيف.
- `art-originals/`: الصور الأصلية.
- `px_assets.py` و`ui_assets.py`: تنظيف الصور. يقرآن من مجلد المرفقات، فعدّل المسار `A` إلى `art-originals/` واحذف اللاحقة `-image` عند إعادة التشغيل.
- `px_build.py`: يدمج الكود والرسومات في ملف واحد.
- `audit.js`: لاعب آلي يختم كل المهام.

ملفات النشر في جذر المستودع، ومجلد `source` ما ينشر على الموقع.
